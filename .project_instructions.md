# BütçeM - Kişisel Finans Yönetimi

## Proje Genel Bakış
FastBudget benzeri kapsamlı kişisel finans yönetim uygulaması. Türkçe arayüz, tek kullanıcılı.

## Teknik Yaklaşım
- Database: PostgreSQL + Prisma ORM
- File Upload: AWS S3 with presigned URLs
- OCR: LLM API (gpt-5.4-mini) ile streaming belge analizi
- Charts: recharts kütüphanesi

## Renk Paleti
- Primary/Accent: Emerald (#10B981)
- Gelir: Emerald, Gider: Red (#EF4444), Borç: Orange (#F59E0B), Alacak: Purple (#8B5CF6)
- Taksit: Pink (#EC4899), Blue (#3B82F6)

## Sayfa Yapısı (Sidebar Navigation)
1. Dashboard (/) - Özet kartlar, grafikler, son işlemler
2. İşlemler (/islemler) - Gelir/gider CRUD
3. Kategoriler (/kategoriler) - Gelir/gider kategorileri
4. Hesaplar (/hesaplar) - Banka, kredi kartı, nakit
5. Borç/Alacak (/borc-alacak) - Borç/alacak takibi + ödeme
6. Taksitler (/taksitler) - Kredi kartı taksitleri
7. Satıcılar (/saticilar) - Satıcı cari hesapları
8. Belgeler (/belgeler) - Fatura/fiş yükleme + OCR
9. Raporlar (/raporlar) - 12 aylık analiz + export

## Veritabanı Modelleri
Account, Category, Transaction, DebtCredit, DebtPayment, Installment, Vendor, Document

## Önemli Kararlar
- Sidebar navigation (collapsible, mobile responsive)
- Seed script ile varsayılan kategoriler ve nakit hesabı oluşturuldu
- OCR streaming ile belge analizi
- Veri export JSON formatında
